Customer Churn Prediction Using Machine Learning¶

Project Overview¶

Customer churn prediction is an important business problem for subscription-based service providers The objective of this project is to analyze customer account data and build a machine learning model that can be identify customers who are likely to cancel their subscription.

The dataset contains customer demographic information, service details, contract information, billing information, tenure, and the final churn status.

The project follows an end-to-end machine learning workflow:

1 - Data loading and exploration 2 - Data cleaning and preprocessing 3 - Feature engineering 4 - Train-test splitting 5 - Machine learning model development 6 - Cross-validation 7 - Model evaluation 8 - Feature importance analysis 9 - Business insights and retention recommendations

The final objective is to build a predictive ML model but also to translate the model's results into practical actions that can help the Customer Success engage customers who are at higher risk of churn.

Problem Statement¶

The company wants to reduce customer churn by finding out which customers are more likely to leave before they actually cancel their subscription. Currently, the company mainly tries to win customers back after they have already left. The goal is to take action earlier and try to retain them.

In this project, I will:

  1. Understand the customer data and look for useful patterns.
  2. Check the data for problems such as missing values, duplicate records, incorrect values, and inconsistent text.
  3. Clean and prepare the data for machine learning.
  4. Create some useful features that can help predict customer churn.
  5. Build and compare two machine learning models.
  6. Use cross-validation to check how well the models perform.
  7. Evaluate the models using Accuracy, Precision, Recall, F1-score, and ROC-AUC.
  8. Select the model that gives the best overall results.
  9. Find out which customer factors are linked with higher churn.
  10. Use the results to suggest practical ways to reduce customer churn.

The main goal of this project is to help the company identify customers who are at higher risk of leaving and take action early through targeted retention efforts.

Business Objective¶

The primary business objective is to identify customers who are at a higher risk of churn and provide the Retention team with actionable information that can support proactive customer engagement.

A successful churn prediction solution can help the business:

  • Identify high-risk customers before they leave.
  • Prioritize retention campaigns.
  • Understand factors associated with customer churn.
  • Allocate retention resources more efficiently.
  • Design targeted offers for specific customer segments.
  • Improve customer retention and potentially reduce revenue loss.

The model should therefore be evaluated not only from a technical perspective but also from a business perspective.

Data Preprocessing¶

For numerical columns, missing values will be filled using the median and the values will be standardized. For categorical columns, missing values will be filled using the most frequent value and then converted into numerical form using one-hot encoding. The preprocessing will be placed inside a pipeline to avoid data leakage.

numeric_pipeline = Pipeline(
    steps=[
        (
            "imputer",
            SimpleImputer(strategy="median")
        ),
        (
            "scaler",
            StandardScaler()
        )
    ]
)

categorical_pipeline = Pipeline(
    steps=[
        (
            "imputer",
            SimpleImputer(strategy="most_frequent")
        ),
        (
            "encoder",
            OneHotEncoder(
                handle_unknown="ignore"
            )
        )
    ]
)

preprocessor = ColumnTransformer(
    transformers=[
        (
            "numeric",
            numeric_pipeline,
            numeric_features
        ),
        (
        "categorical",
        categorical_pipeline,
        categorical_features
        )
    ]
)

Evaluation Function¶

I will create one function to calculate all the required evaluation metrics for each model.

def evaluate_model(
    model_name,
    y_true,
    predictions,
    probabilities
):
    
    return {
        "Model": model_name,
        "Accuracy": accuracy_score(
            y_true,
            predictions
        ),
        "Precision": precision_score(
            y_true,
            predictions,
            zero_division=0
        ),
        "Recall": recall_score(
            y_true,
            predictions,
            zero_division=0
        ),
        "F1-Score": f1_score(
            y_true,
            predictions,
            zero_division=0
        ),
        "ROC-AUC": roc_auc_score(
            y_true,
            probabilities
        )
    }
